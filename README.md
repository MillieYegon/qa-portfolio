## How I approach quality

- **Isolation before speed.** Tests that own their data can run in parallel without flaking.
- **Testability before test count.** Stable test IDs first, then more tests.
- **Measure what the decision needs.** Count escapes by severity per change shipped, and check what the data actually records.
- **Humans approve, agents draft.** AI does the repetitive work; a person decides what becomes part of the suite.
- **Evidence for every verdict.** A pass without proof is not a pass.
